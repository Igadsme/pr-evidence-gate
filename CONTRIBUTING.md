# Contributing

Use Node.js 24, Python 3, npm, and pytest. Run `npm ci`, `npm run typecheck`, `npm test`, and `npm run build` before submitting a change. Add a fixture or focused test for each new classification or security boundary.

Do not add checks that infer contributor identity or that turn an unavailable registry, collection failure, or dynamic import into a definitive defect. Keep evidence bounded and include paths and reproducible commands where possible.
